## Overview
This project performs exploratory data analysis (EDA) on a housing dataset to identify patterns and factors influencing property prices.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Analysis Performed
- Cleaned and transformed raw housing data (price, bedrooms, bathrooms, area)
- Analyzed price distribution across listings
- Examined relationships between price and property features
- Conducted correlation analysis to identify key drivers
- Compared pricing across different cities

## Key Insights
- House prices are evenly distributed across the dataset  
- No strong linear relationship exists between price and features such as area or bedrooms  
- Location does not significantly impact pricing in this dataset  

## Conclusion
This project highlights the importance of exploratory data analysis in understanding datasets and identifying underlying patterns before building predictive models.
